How the value is worked out

Implied value = TVL × the category multiple × growth × maturity × breadth. The multiple is the median market-cap/TVL of listed protocols in the same category, each ratio capped at 5.0 first, then shrunk toward the market-wide median with a prior weight of 3 listed names, clamped to 0.05–1.50. Growth is the protocol's 7-day TVL change, clamped to −60%…+120%, weighted 0.5. Maturity is 0.6 + age/1095 days × 0.4, so a protocol that has run longer with no token counts for more. Breadth is 1 + 0.04 per extra chain, at most 1.20. No protocol name is special-cased: the same function scores every row. A protocol is pre-token when its record carries no token — no market cap, no CoinGecko id, no symbol.
